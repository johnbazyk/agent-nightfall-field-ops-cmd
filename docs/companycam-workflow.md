# CompanyCam Workflow (CMD Secure)

## Purpose
CompanyCam is the source of truth for site photos, camera images, and client completion reports.

## Job Reporter Responsibilities
- Project creation or selection
- Image upload and organization
- Report template design (initial)
- Report generation and client delivery **only after explicit dry-run approval**
- Optional cleanup / standardization

## Client Report Template Outline
The report should include:
1. Cover page (site name, date, CMD Secure branding)
2. Device inventory (cameras programmed, models, IPs)
3. Image gallery (key camera views, before/after if relevant)
4. Recording schedule summary
5. Notes / exceptions
6. Contact information

Design the initial template if none exists and save it as a reusable CompanyCam template when possible.

## Approval Rule
Always produce a dry-run or preview of the report and obtain explicit approval from the Field Supervisor / technician before generating the final version or sharing it with the client.

## Notes
- Use CompanyCam API or desktop/web interface as available.
- Treat tokens as sensitive; do not persist on the field kit.
- Report is client-facing — never send without approval.
